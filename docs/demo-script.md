## Комиссияның жиі сұрақтарына жауаптар

**Неге жай ChatGPT қолданбайсыздар?**
ChatGPT .docx-тің өрісін, қаріп өлшемін, бет нөмірін көрмейді — ол мәтінді ғана оқиды және болжайды. Бізде өлшенетін 13 талапты
бағдарлама дәл тексереді, ЖИ тек түсінуді қажет ететін жерде қолданылады. Сонымен қатар: ережелерді оқытушы бекітеді (бір өлшем),
әр ЖИ тұжырымы дәйексөзбен расталады, жеке деректер жасырылады, нәтиже топ бойынша жинақталады. Бұл чат емес — процесс.

**ЖИ қателессе ше? Қате баға қойса?**
1) ЖИ баға қоймайды — тек ұсыныс; соңғы шешім оқытушыда, интерфейсте ашық жазылған. 2) ЖИ-дің әр тұжырымында жұмыстан
дәйексөз болуы міндетті, бағдарлама оны тексереді; табылмаса — тұжырым «тексерілмеді» болып, есептен шығады. 3) Рәсімдеу
пайызы ЖИ-сіз есептеледі. 4) Регрессиялық тесттер нақты жұмыстардағы күтілетін нәтижелерді тексереді (мысалы, 52 бет,
1,15 интервалдағы 12 абзац).

**Деректер қауіпсіздігі?**
Студент пен жетекшінің аты-жөні, e-mail, телефон ЖИ-ге жібермес бұрын `[ЖАСЫРЫЛДЫ]` болып ауыстырылады. Файлдар тек серверде,
кездейсоқ атпен сақталады; оқытушы жойса — файл да жойылады. API кілті тек орта айнымалысында. Жүктеу 20 МБ-пен шектелген,
файл түрі мазмұны бойынша тексеріледі. Университет ішінде орнатылса, деректер ЕҰУ серверінен шықпайды (ЖИ провайдерін
жергілікті модельге ауыстыруға болады — `core/llm.py` бір интерфейс).

**SmartENU-ға қалай қосылады?**
Ашық REST API және OpenAPI құжаттамасы (`/docs`). Деректер моделі SmartENU құрылымына сәйкес: пән → тапсырма → жұмыс.
Кіру жүйесі бір функцияда (`current_user`) — оны SmartENU SSO токенімен ауыстыру жеткілікті. SmartENU тапсырма жасағанда
біздің API-ге жібереді, нәтижені алып, оқытушы журналына «алдын ала тексерілді» деп белгілейді.

**Басқа пәндерге жарай ма?**
Иә. Ережелерді оқытушының өз құжатынан ЖИ шығарады, оқытушы түзетеді. Курстық жұмыс, БӨЖ, реферат, эссе, зертханалық есеп —
кез келген жазбаша жұмыс. Тек мәтінмен де талап жазуға болады.

**Қолжазба жұмыс ше?**
Бет фотоларын жүктейді; ЖИ қазақ әріптеріне бейімделген OCR жасайды, әр бетке сенімділік деңгейін береді, күмәнді сөздерді
сарымен белгілейді. Құрылым мен әдебиеттер тексеріледі, мазмұн бағаланады. (Әзірге нақты фотолармен кең тестілеу жалғасуда.)

**Қанша тұрады / жылдамдығы?**
Бір жұмыс ≈ 45 секунд (оның 25–35 секунды — ЖИ). Тегін Gemini деңгейінде жұмыс істейді; ауыр жүктемеге billing немесе
университеттің өз сервері керек. Рәсімдеу тексеруі мүлде тегін — LLM қолданбайды.

**ЖИ сервисі қорғау кезінде істемей қалса?**
Модельдер тізбегі автоматты ауысады (Pro → 3.8 Flash → 3.5 Flash). Бәрі қолжетімсіз болса — рәсімдеу есебі бәрібір шығады,
ал «Демо режимі» бұрын нақты жүргізілген тексеру нәтижесін ашық белгімен көрсетеді.
